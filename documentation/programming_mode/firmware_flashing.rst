更新固件
=======================================


二、固件烧录
~~~~~~~~~~~~~~~~~~~~~
将摄像头type-c usb线连接电脑，打开烧录软件软件，选择4.0摄像头固件刷入

.. Attention:: 摄像头更新固件后，搭配乐动掌控最好也更新一次固件
