更新固件
=======================================


固件烧录
~~~~~~~~~~~~~~~~~~~~~
将摄像头type-c usb线连接电脑，打开烧录软件软件，将4.0摄像头系统文件复制到/CanMV/sdcard 覆盖替换

固件系统文件
------------

- :download:`4.0摄像头系统文件 </_static/firmware/AI摄像头4.0替换文件-20250611.zip>`


.. Attention:: 摄像头4.0更新固件后，搭配乐动掌控2.0也在mPython更新一次固件
