传感器模式硬件连接
=======================================

一、AI摄像头4.0与乐动掌控搭配使用
~~~~~~~~~~~~~~~~~~~~~
1、摄像头连接主控硬件
---------------------

如图示将AI摄像头连接至P0、P1引脚（或其他可用串口的引脚）

.. figure:: /_static/image/hardware_connection/1.jpg
    :align: center
    :width: 600


2、编写程序
---------------------
打开mPython软件，连接上乐动掌控，选择连接的引脚，刷入程序

乐动掌控与摄像头成功通信，控制台会输出“==AI摄像头通信成功==”
