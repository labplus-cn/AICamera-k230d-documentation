AI摄像头4.0介绍
==============

产品概述
--------
AI摄像头4.0是一款基于CanMV K230d芯片开发的高性能AI视觉传感器，集成先进AI计算能力，适用于多种计算机视觉应用场景。
作为可编程视觉传感器，它可通过连接主控设备（如掌控板、乐动掌控等），结合mPython等编程软件实现AI应用开发与学习。

主要特性
--------
- 强大的AI算力：内置新一代KPU智能计算单元，支持多精度AI计算
- 丰富的应用支持：

  - 80类物体分类
  - 人脸识别
  - 人脸检测
  - 表情识别
  - 眨眼张嘴检测
  - 人脸关键部位
  - 人脸姿态
  - 手掌检测
  - 动态手势识别
  - 手掌关键点检测
  - 手掌关键点分类
  - 人体检测
  - 跌倒检测
  - 人体姿态识别
  - 人体关键点检测
  - 车牌识别

- 硬件配置：
  - 双核RISC-V处理器
  - 2D/2.5D硬件加速单元
  - 丰富的外设接口
- 产品优势：
  - 低延迟处理
  - 高性能计算
  - 低功耗设计
  - 快速启动能力

技术参数
--------
- 主控芯片：CanMV-K230d（嘉楠科技Kendryte®系列AIoT芯片）
- AI算力：支持多精度AI计算，典型网络利用率大于70%
- 接口：丰富的外设接口支持
- 加速单元：集成2D、2.5D专用硬件加速单元
