主控编程模式
=======================================

* 主控模式上电即玩，运行AI案例模型，拍照录像可保存到u盘。
* 传感器模式既支持代码模式编程也支持图形化模式编程，适合所有人使用。
* 内置AI案例模型，快速上手。
